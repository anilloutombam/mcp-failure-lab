# Code of Conduct

## Our commitment

MCP Failure Lab is committed to providing an open, welcoming, and respectful environment for everyone participating in the project.

## Expected behavior

Community members are expected to:

- Communicate respectfully and constructively
- Keep technical disagreements focused on ideas, evidence, and the work
- Give and accept constructive feedback
- Respect privacy and personal boundaries
- Take responsibility for mistakes and correct them where possible

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, threats, intimidation, or discrimination
- Sexualized language, imagery, attention, or advances
- Personal attacks, insults, trolling, or deliberate disruption
- Publishing another person's private information without permission
- Retaliation against someone who reports a concern in good faith
- Other conduct that would reasonably be considered inappropriate in a professional open-source community

## Scope

This Code of Conduct applies to repository activity, issues, pull requests, reviews, discussions, and other project spaces.

It also applies when someone is publicly representing MCP Failure Lab.

## Reporting

For violations involving GitHub activity, use GitHub's reporting and blocking tools where appropriate.

Do not open a public issue containing sensitive or personal information.

Security vulnerabilities are not Code of Conduct reports. Follow [`SECURITY.md`](./SECURITY.md) to report security issues privately.

## Enforcement

The project maintainer may remove content, close or reject contributions, restrict participation, or block participants when necessary to maintain a safe and constructive project environment.

Enforcement decisions will consider the severity, context, and pattern of the behavior.

Good-faith reports will not result in retaliation.
